# Step 7 Review: Sustainable ML Approach

- Reviewer transcript: transcripts/32_2026-11-03_reviewer_step7.md
- What was reviewed: the diff from step7-start to commit 276df23 (.harness/diffs/step7_diff.patch), with src/preprocess.py opened for context. I read AGENTS.md, PLAN.md and the diff only. I ran no commands that execute code, so every claim below comes from reading the code and the committed result tables.

**Leakage checks (lead engineer's list). I found no defect in any of them.**
1. For every test year t, the mask, scaler, clip statistics and model are fit on `window_years(strategy, t)` only. The clip is the constant `Z_CLIP`. `fit_on_years` calls `check_no_overlap(years, [t])`, which enforces `max(train) < min(test)`, and `Preprocessor.fit` sees only the stacked window rows.
2. The incremental strategy predicts year t first (`model.predict(Z_t)`) and calls `partial_fit` afterwards. The scaler and mask are frozen on 2014-2016. The seen-years assertion runs before every prediction.
3. The static baseline is never updated. `static_from_models` only calls `predict` on the Step 4 objects. `run_incremental` trains a fresh SGD, so the Step 4 SGD is not mutated.
4. All strategies are scored on the same test years, with the same `compute_metrics` (malware is the positive class), and on the same row counts (n = 18,000 / 18,000 / 3,000 x 3). The 2017 rows of static, expanding and sliding are identical, as expected.
5. The sliding window is `range(t-3, t)`. `step7_window_composition.csv` confirms that 2021 uses 2018-2020 only.
6. Per-window preprocessing is refit on that window only.

Evaluation is time-forward, there is a never-updated baseline, and the comparison is like-for-like within a classifier. The comments below are about robustness and how the results should be read.
