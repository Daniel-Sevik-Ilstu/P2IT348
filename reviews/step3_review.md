# Step 3 Review: Preprocess Data for Model Training

- Reviewer transcript: transcripts/14_2026-11-03_reviewer_step3.md
- What was reviewed: the diff from step3-start to commit 18d40c4 (src/preprocess.py, src/main.py, results/step3_*), read with AGENTS.md and PLAN.md only.

Leakage checks (the three points asked for), all passed:
- The minimum-support mask, the all-zero count and the StandardScaler are all learned in `Preprocessor.fit`, which `prepare_split` calls on the training rows only (`src/preprocess.py:115`). Test rows only go through `transform`.
- `split_by_year` calls `check_no_overlap` before it selects any rows, so train and test years cannot share a year or be out of order. The split table shows train 2014-2016 and test 2017-2021.
- Train and test use the same `features` list and the same `mask_`, so the columns and their order are identical. I ran `prepare_split` on the real data (read-only): X_train is (54000, 931), X_test is (45000, 931), both float32, with no NaN in the test output.
- `filter_report` reads the test years, but only to produce a report. It does not feed back into the mask or the scaler.

No High issues found. The comments below are about the filter's stated purpose and about error handling.
